# 界面配置入口精简记录

## Intent：最终目标

减少进入配置前的视觉负担，修复 Header 遮挡，并把调试模式表达为开关。

## Data：执行证据

- 删除入口宣传标题、插画、当前使用标记及专用样式。
- 删除 AI 分支的正文返回链接、编号、大标题、说明和风格区介绍，保留风格选择、生成与应用流程。
- 三个配置入口改为同组紧凑列表，只有图标、标题、说明和箭头。删除编号、标签、重复底部说明与口号。
- 根据用户最新截图，将三个入口的上下 padding 从 20px 缩为 12px，并移除 92px 最小高度，让行高随内容自然收紧。
- 页头标题随当前状态显示“界面配置”“AI 生成”或“自动适配”。
- main 标记 content-under-header，退出公共伪元素占位；新增 header-spacer div，height 使用与 Header 相同的安全区加 44px 变量，margin-bottom 为 12px。
- 调试工具右侧替换为 role=switch 的真实开关。状态来自已保存 component；没有显式配置时读取布局记录后判断，未完成读取前禁用。
- 开启保存调试模式；关闭恢复正常组件面板。无已保存布局时打开编辑器，不制造空正常面板。
- 切换保留原有保存通道，不修改固件。失败保留原状态并显示错误。

## Edges：边界与限制

- 用户明确不要求浏览器 UI 确认，因此仅依据截图、源代码与构建验证。
- 不新增测试用例，只调整现有构造器桩与过期预期。
- 自动适配、AI 生成、保存与编辑器路由功能保留。

## Answer：交付与验证

- 本地构建通过；修改后相关四个文件 49 项已有测试通过。
- 调试开关、AI／自动适配重排和 Header 返回调整后，受影响的界面配置页 22 项已有测试再次通过，本地构建通过。
- 后续 AI 页改为三种小型风格选择、同卡片内的需求输入与生成按钮、下方独立效果预览；删掉模拟设备数据的风格大样例。
- 自动适配移除内部返回链接、编号、宣传标题与说明，只保留可用部件数量、刷新、预览和应用。
- AI／自动适配的 Header 返回调用内部 closeEditor；入口页仍走标准路由返回。手动编辑 Header 改为 ion-back-button，移除写死设备详情地址的 leave 方法；保存成功去向不变。
- 手动编辑已有路由 canDeactivate 保留。Ionic 返回仅在没有历史时使用 defaultHref，不把用户取消未保存确认误当作缺失历史。
- 架构与数据流见 [执行计划](./界面配置入口精简计划.md)。

## 自我批判

原设计将三个简单入口展开成大量重复文案和装饰，增加了手机页面滚动成本。删除介绍后，又暴露出正文占位对隐式选择器的依赖；本次按用户要求改为显式同高占位。调试模式是持久状态，箭头暗示导航而不说明当前状态，改为开关才符合含义。实际毛玻璃与手机尺寸仍需用户界面反馈，未冒充已做视觉验证。
