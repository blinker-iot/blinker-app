# 组件自适应高度同步执行记录

## Intent：最终目标

以组件库预设为标准统一高度行为，修正滑块标题间距，并将编辑器 swap 改为带让位动画的网格插入排序。

## Data：实施证据

- 从 PageLayoutPanel 抽取共享网格样式，编辑器三个模式及属性预览复用。半宽单元仍保持行高；全宽单元允许按内容撑高，但保留 --fill-h，由组件自身的 fills-rows 声明决定是否仍需行高。
- 组件库当前 46 个默认预设在两列布局下：24 个全宽内容自适应、8 个全宽保留行高、14 个半宽保留行高。实现没有按预设 ID 编写特殊分支。
- 全宽保留行高的默认预设为 direction-pad、servo-dial、rgb-picker、motor-levels、backlight-level、temperature-trend、light-trend、adc-trend。
- gradient 使用明确的标题下边距 12px，并取消该间距处的通用 gap 与自动顶边距，避免重复叠加。
- 属性预览不再给卡片强制固定高度；仅限制预览滚动区域最高 42dvh，保留下方属性区空间。添加目录也保持半宽行高，并让全宽继续遵守组件本身的规则。
- 新增 @dnd-kit/dom 0.5.0，编辑器移除 Gridster 固定坐标渲染。Sortable 负责指针、键盘、碰撞、自动滚动和拖动反馈；Angular 负责临时列表顺序。
- 拖动到目标位置时执行插入。结束后把可见顺序合回完整列表，保留隐藏部件的序列位置，再按真实宽高重新计算八栏坐标，调用现有 commit 一次。取消、无变化或文档已被替换时不提交排序。
- 手机网格由 row dense 改为 row，防止后面的半宽卡片回填到前面，造成视觉顺序与保存顺序不一致。
- 让位动画测量所有非拖动卡片的前后位置，包含索引未变化但因换行产生的位移。240ms 缓出动画作用于内部卡片，外层网格单元保持最终碰撞位置。
- 最终坐标测量等待 dnd-kit Feedback 的 MutationObserver 移动占位节点后执行。连续移动先读取当前动画位置，再取消旧动画并衔接新动画；销毁时释放动画。

## Edges：边界与限制

- 保存协议、部件宽高、绑定和属性格式保持原有语义；插入排序会正常调整后续部件坐标。
- 本次不新增测试用例，不调用浏览器做 UI 确认。用户曾反馈无让位动画，已据此补齐实际坐标动画，但自动验证不等同于触摸手感实测。
- 动画尊重系统减少动态效果设置。
- @dnd-kit/dom 为新增直接依赖；原有 Gridster 依赖仍供其他页面使用。

## 自我批判

最初把全宽概括为自适应不够准确；用户明确以组件库预设为准后，核对了组件自身的 fills-rows 声明，最终复用原规则而没有新建高度白名单。第一版依赖 Sortable 索引变化触发动画，无法覆盖不同尺寸网格中索引未变化的被动位移；现改为实际坐标差动画，并处理占位节点异步移动，避免只补一个 CSS transition 却没有可靠起终点。仍需承认未做浏览器和真机触摸验证，不能把构建通过表述为动画手感已验证。
