# 添加部件筛选与样式修正执行记录

## Intent：最终目标

添加部件面板简化为字段选择与组件预览；字段下拉菜单与面板风格一致，组件选项符合字段能力。

## Data：实施证据

- 移除搜索输入、对应状态与过滤分支，以及预览卡片下方的名称／宽高说明行。
- 字段按钮占满一行，最小高度 44px；移除原 ion-select 外层 padding 与内部最小高度叠加的问题。
- 使用 Ionic 的显式 popover 和单选组，以完整字段按钮为锚点，size=cover 跟随按钮宽度。关闭三角箭头和背景遮罩，列表采用 14px 字体与 44px 选项高度，超过高度后滚动。
- 弹层独立应用现有 ui-theme，避免 overlay 脱离页面后回到 Ionic 默认白底蓝色风格。选项保留单选组键盘交互，选择后关闭。
- 新增 presetMatchesField，目录展示和实际添加都经过该判断。既有 variantsFor 继续负责旧布局的兼容校验。

| 字段能力 | 添加目录规则 |
| --- | --- |
| 可写布尔属性 | 开关类及状态类；不出现大数字、趋势、环形或日志 |
| 只读布尔属性 | 状态类 |
| 数值属性 | 数字、趋势、状态；环形需有效上下限；可写且有范围时提供范围控件 |
| 文本属性 | 状态；非枚举文本可以记录日志；可写文本可以输入 |
| 枚举文本 | 可写时提供选项控件，阻止任意文本输入 |
| 事件 | 状态与事件记录 |
| 动作 | 继续使用原有无参／布尔按钮、指令选项或数值动作步进器约束 |
| RGB | 沿用原有颜色声明约定，仅提供色盘 |
| 档位 | 必须完整覆盖整数步长范围，包含起点后不超过 12 个值 |
| 倒计时 | 必须明确是秒单位、下限为零，确保取消可以提交零 |

## Edges：边界与限制

- 不按字段 key、演示名称或预设 ID 猜测设备用途。
- 颜色识别沿用项目既有声明约定，字段元数据没有另外引入颜色类型。
- 对旧协议“新字段”，用户正在定义字段类型，仍根据所选部件生成其元数据；已有字段才使用目录适配筛选。
- 不回写或迁移旧布局，不让新目录规则导致已有面板解析失败。
- 不新增测试用例，不调用浏览器进行视觉确认。

## 自我批判

只修改字段按钮样式不足以处理独立挂载的弹出层，因此后续根据用户截图改为显式 popover，使宽度锚点和主题来源都明确。字段筛选也不能直接收紧旧布局解析函数，否则旧面板可能打不开；本次限制在添加入口，并让实际添加执行同一判断。数值状态组件本身支持告警展示，因此复核时保留其适配，没有把“布尔字段不应出现数字图表”过度扩展成禁用数值状态。自动检查不覆盖实际弹出位置与触摸视觉效果。
