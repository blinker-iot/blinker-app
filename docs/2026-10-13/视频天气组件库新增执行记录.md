# 视频天气组件库新增执行记录

## Intent：最终目标

在组件库中交付重新设计的全宽视频与天气组件，保留既有数据格式和三种主题的整体设计语言。

## Data：实施结果

### 视频

- 新增 `device/v2/widgets/video` 独立组件，使用已有 `url / str / mode` 字段。
- 画面固定 16:9；上方展示标题与连接状态，下方提供格式信息与设置入口。
- 空源时呈现真实的待配置状态，不伪造视频内容或播放成功。
- MJPEG 使用图像元素；HLS 优先使用原生能力，否则使用已有 `hls.js`。播放器使用原生播放控制。
- 播放失败显示重新连接入口；切换地址和组件销毁时释放旧媒体资源。
- HLS 库按需加载；每次播放源变化创建新的媒体会话，模板事件、动态加载和播放 Promise 都校验会话版本，忽略旧源回调。
- 组件库离页时暂停并清理媒体，返回时按当前配置恢复，覆盖 Ionic 缓存页面不触发销毁的情况。
- 根据截图反馈，将卡片底部 padding 从 18px 收紧到 10px，手机布局从 14px 收紧到 8px，同时减少画面和页脚间距。

### 天气

- 新增 `device/v2/widgets/weather` 独立组件，直接使用旧标准化类型，不复制供应商解析逻辑。
- 根据用户“紧凑、精致”的反馈，城市、温度、天气状况和图标改为一行，去掉大面积纵向留白。
- 实况／逐小时预报切换显示，避免把所有信息堆叠成高卡片；常用指标保持一排四项，极窄容器才改为两列。
- 三小时预报采用紧凑的图标与温度并排结构，保留时间、天气和降水概率；按最新反馈，实况指标全部直接显示，不再折叠。
- 指标等宽居中排列，每列之间使用垂直居中的 24px 短分割线；极窄容器按两列布局调整行首分割线。
- 风速由 km/h 换算为节（除以 1.852，显示一位小数）；气压由 hPa 换算为巴（除以 1000，显示两位小数）。仅改变显示，原值保留于输入数据与指标 title 中。
- 当前天气图标和普通预警去除橙色，逐小时天气图标去除蓝色，使用正文色；降水概率与辅助信息使用次要文字色，深色主题自动适配。
- 温度单位改为普通行内元素，避免全局上标定位规则使度数符号偏移到城市附近。
- 预警使用可展开的信息行，保留描述、建议、来源与发布时间。
- 演示数据沿用旧杭州天气示例，时间在打开页面时生成。

### 库页与参数

- 新增“视频与天气”分组，两个卡片都占据 8 栏全宽，计数增加 2。
- 沿用长按/右键选中方式；媒体专属参数面板负责标题、视频地址/格式/播放方式、天气显示内容。
- 参数只影响本页预览，配置片段标记为“预览配置”。
- 共享 PageLayout schema、正式设备 renderer、presets、旧组件迁移和后端协议均未扩展。

## Edges：边界与自我审查

- 天气来源是外部天气服务，不能伪装为设备标量字段；当前仅将其稳定的展示模型用于组件库。
- 已向用户明确：原视频流来自硬件摄像头，设备上报 `device.data[key]` 中的 `url / str / mode`，旧组件优先使用上报值；新组件保留字段格式，但本次只接入组件库，尚无正式设备订阅入口。
- 已核对旧天气地区逻辑：优先 `device.config.position.location = [经度, 纬度]`，未设置时请求浏览器定位。设备位置页支持修改坐标、当前位置和预设位置；旧天气组件本身没有独立城市选择器。新库页为固定杭州示例，未声称支持真实地区切换。
- 仓库没有可播放的演示视频，空源界面是实际初始状态。输入地址后才加载媒体，不能把空源演示描述成真实播放验证。
- 没有复用旧组件 HTML/SCSS；仅复用公共卡片基础、主题令牌及数据类型。
- 天气模型的类型引用暂时位于旧目录；本次未为了目录层次迁移大型适配器，避免扩大修改范围。
- 逐小时预报和指标对空值保留占位语义，没有将缺失值伪造为零。
- 紧凑数值通过真实单位换算得到，没有截断单位或针对示例数值写死结果；未知单位不猜测转换。
- 两个只读子任务核对了数据边界与集成范围；静态审查不替代真实浏览器验收。
- 初版天气同时展开主信息、指标和预报导致卡片过高；已按截图反馈改为分层切换，而非仅缩小字体。
- 没有调用浏览器，没有读取真实天气密钥、请求定位或真实天气 API，没有真实流媒体播放验收。
