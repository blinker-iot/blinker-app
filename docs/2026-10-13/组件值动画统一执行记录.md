# 组件值动画统一执行记录

## Intent：最终目标

组件值更新统一具有过渡，滑块位置与读数同步平滑，差值徽章的箭头和数字保持垂直居中。

## Data：实施证据

- 抽出 AnimatedNumber，由范围控件和只读数值共用单一连续帧循环。数值更新只改变目标，最后一次更新后 180ms 精确收敛。
- 范围控件的 level 改用显示值，因此亮度／色温滑块手柄、大块滑块填充、拨盘指针和数字使用同一过渡。实际 value、ARIA 和发送命令仍取真实值。
- 移除大块滑块原来的独立 CSS 进度过渡及 moving 分支，避免叠加两套缓动。
- ReadingWidgetBase 新增独立 displayNumber／displayReading／displayLevel；原 number、reading、describe、告警和历史语义保持不变。
- 大数字紧凑显示也读取显示值；其 ngOnChanges 调用父类后再记录真实差值。超出安全整数范围的 bigint 保留原始格式，仅做文字过渡。
- 环形读数和图形进度同步插值；趋势最新读数插值，历史采样与图形数据不伪造中间值。
- 字形指令统一命名为 ValueTransitionDirective，接入状态、倒计时、动作次数／状态、HEX、日志条数、档位、开关状态与附属读数等动态文字。
- 静态标题、刻度、预置值不播放动画；历史记录沿用原入场显示，不对整列历史数字进行插值。
- 根据差值徽章截图修正：文字动画仅改变透明度，移除强制 inline-block 和纵向位移；徽章明确使用 inline-flex、align-items:center、4px 间隔和统一行高。

## Edges：边界与限制

- 状态语义、颜色编码、时间和历史是离散内容，只做文字过渡。文字动画不干预真实计时和业务判定。
- 继续遵循系统减少动态效果偏好，初次显示直接使用当前值，销毁时取消动画。
- 未调用浏览器或板卡进行视觉、硬件验证；未新增测试用例。

之前把“数值插值”“数字文字过渡”和“控件位置过渡”当成同一个效果，导致用户连续指出遗漏。这次分别核对显示入口与几何入口，保留独立真实值，避免为了视觉效果改变指令或历史数据。文字层增加位移又破坏了差值徽章对齐，现已删除这项多余行为，仅保留淡变，并让布局职责回到组件样式。没有浏览器实测，因此不能把构建与单元回归表述为视觉验收通过。
