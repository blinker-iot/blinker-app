# 定时组件圆环重设计执行记录

## Intent：最终目标

落实用户选定的“倒计时放在圆环中央”，以及后续明确的删除预计执行区域、圆环水平居中并放大。

## Data：实施证据

- 环形模式改为 SVG 圆环与居中文本叠放，中央呈现剩余时间，下方呈现配置的动作文字。
- 用户再次反馈左右过空后，将圆环直径上限由 132px 增至 220px。中央数字按直径的 22% 缩放，小时格式按 15% 缩放。
- 根据用户第二轮截图反馈，删除预计执行区域及其专用样式；圆环在卡片主体中水平居中。
- 主体使用 220px 的弹性基准高度与尺寸容器；圆环取 220px、可用宽度、可用高度的最小值，避免在固定高度网格内裁切。
- 删除原先按卡片宽度选择两种固定直径的分支，数字随圆环实际尺寸缩放。
- 属性编辑器将定时组件的 `actionText` 改为关闭／开启选择，沿用已有存储字段、校验和保存路径；其他组件的文案编辑保持不变。
- 修改范围为定时组件模板、样式和共享属性编辑器中的定时专属分支；保留既有数值动画。

## Edges：边界与自我审查

- 没有更改计时、进度比例、时长预设、取消命令、设备协议或存储模型。
- 没有更改条形和文字模式，也没有更改共享卡片样式。
- 小卡片中的长动作文字会省略，小时格式会缩小字号；极端长时长仍需真实界面验收。
- 本次按照用户明确选择直接调整现有组件，没有扩展为其他界面的重设计。
- 初版加入独立执行时间未符合用户期望，已按反馈移除；最终视觉中心只保留圆环、剩余时间和动作。
- 开启／关闭选项定义的是显示文案，实际命令依然只包含秒数。设置旁已明确提示与设备实际定时行为保持一致，不将文案配置伪装为固件动作配置。
- 未进行浏览器视觉验收。构建只能证明模板和样式可编译，不能证明所有网格尺寸下的视觉效果。

## Answer：交付与验证

- 已交付水平居中的放大圆环、中央倒计时、关闭／开启文案选择，以及删除预计执行区域后的简化布局。
- `npm run build:local -- --progress=false` 构建通过。
- `git diff --check` 通过；未新增或运行测试用例，未调用浏览器。
- 架构图和数据流图见同目录《定时组件圆环重设计计划》。
